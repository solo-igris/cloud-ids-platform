# AI-Powered Network Defense Platform

A free, local intrusion detection and response project.

## Goal

Build a system that:

1. Reads safe example network data.
2. Detects suspicious activity.
3. Creates an alert.
4. Requires human approval.
5. Simulates isolating the suspicious service.
6. Stores an audit record.
