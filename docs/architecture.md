# Project Architecture

This project will work in these steps:

1. Use safe example network data.
2. Check the data using security tools called Zeek and Suricata.
3. Clean and organize the detected data.
4. Check whether the activity looks suspicious.
5. Create an alert if it is suspicious.
6. Require my approval before taking action.
7. Simulate isolating the suspicious container.
8. Save a record of what happened.
